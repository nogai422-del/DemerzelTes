# Telethon: вход по QR-коду

Добавлен вход в пользовательский Telegram-аккаунт без SMS и служебного кода.

1. Сохраните API ID и API Hash либо заполните их на странице Telethon.
2. Нажмите «Создать QR-код для входа».
3. В официальном приложении Telegram откройте «Настройки → Устройства → Подключить устройство».
4. Отсканируйте QR-код и подтвердите вход.
5. В админ-панели нажмите «Проверить подтверждение».

После подтверждения StringSession сохраняется в основной базе Demerzel. QR-клиент хранится только в памяти процесса на время авторизации. При перезапуске приложения создайте новый QR-код.
