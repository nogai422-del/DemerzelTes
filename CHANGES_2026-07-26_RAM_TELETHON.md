# Demerzel — стабильность RAM, реакции и участники

## Выполнено

- Очередь сообщений больше не хранит блокировку каждого когда-либо встречавшегося чата навсегда.
- Фоновые задачи отправки учитываются, удаляются после завершения и отменяются при остановке приложения.
- Блокировки предупреждений пользователей переведены на слабые ссылки и освобождаются автоматически.
- При штатной остановке закрывается очередь отправки и HTTP-сессия Telegram-бота.
- Уведомление об отсутствии доступа к реакциям отправляется обычным сообщением, а не ответом на исходное сообщение.
- Добавлен режим функций до `/bv`: `silent` (молчаливый запрет), `notify` (запрет с уведомлением), `allow` (разрешить). Настройка находится в разделе «Этапы анкеты».
- Добавлен модуль синхронизации участников через Telethon и кнопка в разделе «Участники».
- Синхронизация обновляет имя, username, Telegram-статус, последнее появление и признак присутствия в чате, не удаляя накопленную статистику.
- Добавлен журнал последней синхронизации: найдено, новых, обновлено, отсутствует, ошибка.

## Новые переменные окружения

```env
TELETHON_API_ID=12345678
TELETHON_API_HASH=ваш_api_hash
TELETHON_SESSION=/data/demerzel_telethon
```

При первом запуске Telethon может запросить авторизацию аккаунта. Для сервера удобнее заранее создать файл сессии локально и перенести его в постоянный каталог. Аккаунт должен иметь доступ к синхронизируемому чату.

## Обновление

1. Сделайте резервную копию `database/database.db`.
2. Замените файлы проекта содержимым архива, не удаляя постоянный каталог базы.
3. Установите обновлённые зависимости: `pip install -r requirements.txt` или пересоберите Docker-образ.
4. Добавьте переменные Telethon, если нужна синхронизация участников.
5. Перезапустите приложение.

Миграции таблиц выполняются автоматически. По умолчанию функции до `/bv` блокируются молча.

## Настройка Telethon через админ-панель

Добавлен раздел **Участники и анкета → Telethon**. В нём доступны:

- включение и выключение интеграции;
- API ID и API Hash;
- выбор session-файла или StringSession;
- основной ID чата;
- ручная проверка авторизации;
- ручная синхронизация;
- автоматическая синхронизация с интервалом от 15 минут.

API Hash и сессия после сохранения не выводятся целиком. Пустое секретное поле при повторном сохранении сохраняет прежнее значение.
