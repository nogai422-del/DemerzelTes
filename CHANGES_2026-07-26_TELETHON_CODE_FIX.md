# Исправление авторизации Telethon

- Поле ввода кода теперь отображается всегда до завершения авторизации.
- После запроса отображается способ доставки кода Telegram и номер телефона.
- Добавлена подсказка, что код обычно приходит в служебный чат Telegram внутри приложения, а не по SMS.
- Сохраняются тип доставки, следующий способ доставки и таймаут повторного запроса.
- Последняя ошибка запроса кода показывается непосредственно в блоке авторизации.
- Кнопки запроса и подтверждения кода доступны одновременно.
